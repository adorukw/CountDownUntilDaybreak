## 🧠 核心架构思路

### 1. 关于「要不要画整张地图」—— 用 Chunk 拼接法

**不画一整张大地图。** 画不起来——6 分钟跑酷，要保证每一段都有可玩性，手画一张几千米长的地图既累又难调平衡。

推荐方案：**Chunk 拼接 + 半随机生成**

```
┌─────────┬─────────┬─────────┬─────────┬─────────┬─────────┐
│ Chunk A │ Chunk B │ Chunk C │ Chunk D │ Chunk E │ Chunk F │ → 玩家向右跑
│ (城堡内)  │ (城堡内)  │ (出口)   │ (森林)   │ (森林)   │ (森林)   │
└─────────┴─────────┴─────────┴─────────┴─────────┴─────────┘
           ↑ 已离开屏幕的         ↑ 视口         ↑ 待生成的
             回收重用                            (预生成2-3个)
```

**做法：**
- 每个 Chunk 就是一个**固定宽度（比如 1280px = 一屏）**的地图片段
- 每个 Chunk 包含：平台排列、障碍物（尖刺/墙/坑）、道具位置
- 在 C 代码里**用结构体数组定义 Chunk 模板**，而不是靠 Tiled 加载（初期可以硬编码，后面可以加 JSON 加载）
- 游戏运行时，维护一个 `chunk_queue`，每次视口移动到下一个 chunk 边界时，**从模板池里随机选一个追加到尾部**，同时**删除已经离开屏幕的 chunk**

这样你只需要设计 **10-15 个不同的 Chunk 模板**，游戏就能组合出无限长的地图。而且每个 chunk 的障碍密度/类型可以随时间递增。

### 2. 城堡内 → 森林的过渡

城堡和森林实际上是**两个不同的 Chunk 模板池**：

```
Game Progress:
  0:00-3:00 (12PM-3AM) → 城堡池
  3:00-3:30 (过渡)    → 城堡出口特殊 chunk（大门、断桥、跳崖…）
  3:00-6:00 (3AM-6AM) → 森林池
```

Chunk 有一个 `theme` 字段：
```c
typedef enum {
    THEME_CASTLE,
    THEME_CASTLE_EXIT,
    THEME_FOREST
} ChunkTheme;
```

渲染时根据当前 chunk 的 theme 决定 tileset、调色板、背景色。

### 3. 时间系统与天空渐变

**计时逻辑：**
```
游戏总时长 = 360秒(6分钟)
游戏内时间跨度 = 6小时(12PM → 6AM)
换算: 1现实秒 = 1游戏分钟
```

```c
typedef struct {
    float elapsed;      // 已过游戏分钟数 (0~360)
    int hour;           // 当前小时 (0~6, 0=午夜12点)
    int minute;         // 当前分钟 (0~59)
    float sky_t;        // 0.0~1.0 天空插值因子
} GameClock;

void clock_update(GameClock* c, float dt) {
    c->elapsed += dt;   // dt是秒数 = 游戏分钟数
    c->hour = (int)(c->elapsed) / 60;
    c->minute = (int)(c->elapsed) % 60;
    c->sky_t = c->elapsed / 360.0f;  // 0→1
}
```

**天空渐变**用两个关键帧颜色做线性插值：

```
午夜(12PM)   →  黎明前(4AM)   →  日出(5AM)   →  早晨(6AM)
#0a0a1a        #1a1a3a          #4a2a1a        #87CEEB
(深蓝黑)        (深蓝)           (橙红)          (晴天蓝)
```

渲染时把 sky_t 映射到这几个颜色区间，用 `SDL_SetRenderDrawColor` 画背景矩形或者用渐变纹理。森林阶段能看到天空，城堡内则用固定的暗色调背景。

### 4. 追逐系统（吸血鬼）

```
    ← 屏幕左边缘     ← 吸血鬼位置     ← 玩家位置  → 屏幕右边缘
    [   死亡区   |   追逐区   |   安全区   |   前方 ]
```

- 吸血鬼不真正"在"关卡里跑，而是**跟着玩家水平移动，带一个延迟偏移**
- 吸血鬼的速度 = 玩家速度 × (1.0 + 难度系数)
- 难度系数随时间从 0.0 缓慢增长到 0.3 左右
- 如果吸血鬼的 x 坐标追上玩家的 x 坐标 → 游戏结束
- 视觉效果：吸血鬼始终在屏幕左侧附近，越来越逼近
- 可以加"回头看一眼"的动画，看到吸血鬼越来越近

### 5. 玩家操作

```
自动向右跑（恒定速度，有加速度）
↓
跳跃（空格/Z/↑/W）
滑铲（↓/S）— 躲低矮障碍
二段跳（可选，取决于开局选的道具）
冲刺（可选）
```

### 6. 开局三道具

简单但影响玩法：

| 道具 | 效果 |
|------|------|
| 🥾 **加速靴** | 跑速+20%，但操控难度略增 |
| 🛡️ **护身符** | 可以挡一次吸血鬼的"抓取"（容错） |
| 🔭 **夜视镜** | 森林段视野更亮，障碍提前显示 |
